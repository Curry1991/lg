I think I figured out why it doesn't pick up our changes every time on
webOS 4.x+. It works on 3.x since they just list files and add new
permissions if a new file pops up on the filesystem. (I was developing
it originally on 3.x and tested it thoroughly there) But on 4.x+ they
added these "manifest files" and only reload specific configuration file
if version listed in that manifest changes from the last loaded manifest
version. We don't actually do that, so the implication is that for
example when updating Homebrew Channel on 4.x+ you'll get "Root status:
unelevated" until you reboot the TV. (which is kinda concerning)

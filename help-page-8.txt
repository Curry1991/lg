h_ttu 06/11/2026 1:37 PM
First you create an automation in home assistant and edit the yaml:
    alias: TV Brightness - Sun Elevation Based
    description: Adjust TV brightness based on sun elevation
    triggers:
      - minutes: /2
        trigger: time_pattern
    conditions:
      - condition: state
        entity_id: media_player.lg_webos_tv
        state: "on"
    actions:
      - action: shell_command.set_tv_brightness
        data:
          brightness: >
            {% set elevation = state_attr('sun.sun', 'elevation') %} {% set
            min_brightness = 20 %} {% set max_brightness = 100 %} {% set max_elev =
            50 %} {% if elevation <= 0 %}
              {{ min_brightness }}
            {% elif elevation >= max_elev %}
              {{ max_brightness }}
            {% else %}
              {% set ratio = elevation / max_elev %}
              {% set curved = ratio * ratio * (3 - 2 * ratio) %}
              {{ (min_brightness + (max_brightness - min_brightness) * curved) | int | round(0) }}
            {% endif %}
    mode: single
    Then you add these lines to homeassistant's configuration.yaml:
    shell_command:
      set_tv_brightness: >-
        ssh -tt -o StrictHostKeyChecking=no -i /config/.ssh/webos_tv_key root@192.168.1.133 "/home/root/set_backlight.sh {{brightness}}"
And at last you create set_backlight.sh to /home/root/ on the TV that
has just this command:
luna-send -f -n 1 luna://com.webos.settingsservice/setSystemSettings "{\"category\":\"picture\",\"settings\":{\"backlight\":$1}}"
Then chmod +x set_backlight.sh Also IIRC you need to install the
Terminal & SSH app from HACS or something. Obviously create the key pair
for SSH authentication, or just use password authentication in the ssh
command (edited)

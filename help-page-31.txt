mr.meorzipan 07/31/2024 5:12 AM
That error is caused by the certificate being outdated and thus no
longer usable to connect to domains. Think of when you connect to a
website and you see HTTPS infront of URL, it's that, it can't reach
Github because certificate is not usable. So it must be updated. This
can be done. For WebOS, whenever you use webbrowser or some apps, you
can update/replace the certificate by overlaying the old certificate and
configuration files with mount --bind in a script, which is like
replacing files (except it's virtual, so programs think it's replaced,
but not done on disk, so reboot of TV it's gone, no harm done), luckily
for you, a script was made, it is linked in FAQ thread:
https://discord.com/channels/407937994037919756/1254456314055364659 As
for Homebrew Channel (HB), replacing certificate and configuration on
the TV doesn't work, instead a new update for HB needs to be made
containing certificate and fix, which was done, however, is not official
yet, an IPK was shared by HelloBox, but is still in testing phase, users
on Github have reported it works though, next official release, being
version 0.7.0, will contain fix. The FAQ thread i link explains and
links you where to go for the test IPK.
https://discord.com/channels/407937994037919756/1254459326920396800
Before testing, install 'Safe Updater' and run once so it gets root
privileges. So if HB fails due bug in test IPK, you have da safety
net...of course, this assumes your TV's rooted. You can install the test
IPK file with WebOS Dev Manager:
https://github.com/webosbrew/dev-manager-desktop/releases Or if you want
to use cli through ssh, you can run these 2 commands:
    curl -L -o /tmp/hbchannel_0.7.0-test2.ipk https://github.com/throwaway96/webos-homebrew-channel/releases/download/v0.7.0-test2/org.webosbrew.hbchannel_0.6.3_all.ipk
    luna-send-pub -i 'luna://com.webos.appInstallService/dev/install' '{"id":"com.ares.defaultName","ipkUrl":"/tmp/hbchannel_0.7.0-test2.ipk","subscribe":true}'

how to install apps without Homebrew Channel

While installation via Homebrew Channel is mostly broken at the moment, there are other ways to install apps. Note: If you're reinstalling/updating Homebrew Channel itself and your TV is rooted, remember to elevate it after installing and before rebooting with /media/developer/apps/usr/palm/services/org.webosbrew.hbchannel.service/elevate-service. Alternative ways to install apps: * Using https://github.com/webosbrew/dev-manager-desktop" target="blank" rel="noopener noreferrer">Dev Manager from another computer (currently does not run on phones). Using ares-install from https://github.com/webos-tools/cli" target="blank" rel="noopener noreferrer">the webOS CLI tools. It will upload the IPK from your machine to the TV and install it. You'll need to set up the device first with ares-config. Use the tv profile. Note that ares-install can be very unreliable and occasionally requires dozens of attempts before it works. Using the command line on the TV via SSH/telnet (or if you want to be fancy, serial). You can either download the IPK directly on the TV, as shown here (you'll need to know the URL of the IPK), or upload it from your computer/phone via SFTP (just skip the curl line and change ipkUrl to wherever you uploaded it). You can hit control+C once luna-send-pub gets to the installed (or failed) state, or you can wait for it to time out (15 seconds specified below; increase/remove this if you have an especially large app). 
    curl -k -L -o /tmp/app.ipk '<URL goes here>'
    luna-send-pub -w 15000 -i 'luna://com.webos.appInstallService/dev/install' '{"id":"com.ares.defaultName","ipkUrl":"/tmp/app.ipk","subscribe":true}'

Discord formatting

Discord formatting is based on Markdown. To avoid link previews, use angle brackets (<>) around URLs, e.g.: \<http\://www.example.com/> ➡️ http://www.example.com For monospace text, enclose the text in backticks (\\), e.g.: \x = sum(list)\ ➡️ x = sum(list) * For multiple-line monospace text, open and close with three backticks (\\\`), e.g.: \\\` hello world \\\` ➡️ 

  hello
  world
  
* For syntax highlighting, put the language (or whatever) after the opening three backticks, e.g.:  
  \`\`\`c++  
  std::pair<pbnjson::JValue,pbnjson::JValue>::pair<char const(&)[3],pbnjson::JValue&,true>(v21, "id", &v17);

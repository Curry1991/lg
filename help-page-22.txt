What is failsafe mode? Why do I keep getting failsafe mode messages?
Homebrew Channel includes a script that it runs at boot named
startup.sh. It is located in /var/lib/webosbrew and is responsible for:
starting the telnet and SSH servers (if enabled) blocking updates (if
enabled) disabling certain webOS telemetry systems running user/app
startup scripts in /var/lib/webosbrew/init.d (which we will refer to as
"user scripts") Failsafe mode exists primarily to provide a way to
recover if user scripts break something. In failsafe mode, startup.sh
only starts a telnet server and exits. This means that none of the
actions listed above occur. It is triggered when startup.sh runs but
does not finish. startup.sh contains a 10 second wait after executing
user scripts and before clearing the flag that triggers failsafe mode.
Therefore, failsafe mode will be triggered when startup.sh runs and:
startup.sh does not finish (including because of errors in user scripts)
the TV turns off/reboots within 10 seconds of the user scripts finishing
To avoid triggering failsafe mode, make sure you do not turn off/reboot
the TV within approximately 45 seconds after booting. The issue of
failsafe mode triggering unnecessarily is exacerbated by the relatively
late execution of startup.sh using the current autostart mechanism.
Since it does not start running for a while after boot, the period
during which rebooting will trigger failsafe mode will occur a while
after boot. For example, say that startup.sh begins running 30 seconds
after boot. If we estimate that it takes 5 seconds to complete
(including user scripts), then the period during which rebooting would
trigger failsafe mode is from 30 to 45 seconds after boot.

handleCPHotkeys(key, pressed, autoRepeat): 1. gets the powerOnReason
with getPowerOnReason(key) 2. checks
isHotkeyActive(powerOnReason, pressed) (if not, return
KeyPolicy.Accepted) 3. gets appId with getHotkeyAppId(powerOnReason) 4.
does special handling for: WebOS.Key_webOS_USP, WebOS.Key_webOS_New,
WebOS.Key_webOS_ALEXA, WebOS.Key_webOS_GoogleVoice 5. launches appId
(potentially with params, but those don't seem to be used) unless it's
already running+has focus there is some special-case stuff for hotel
mode in japan and aplus/atelier rolling screens (edited)
hellobox. 10/22/2023 5:10 PM
getHotkeyAppId(reason) looks up the appid in
cpHotkeyInfo["mapping_info"]
10/22/2023 5:09 PM
isHotkeyActive(reason, pressed) mainly checks whether reason (which is
one of those "power on reason" strings like "amazon") has isActive set
in its cpHotkeyInfo["mapping_info"] entry
10/22/2023 5:07 PM
getPowerOnReason(key) converts key (which is a keycode, e.g.
WebOS.Key_webOS_Amazon) to a string (e.g. "amazon") that can be used as
an "index" (actually it can't be directly used as an index because of
their weird structure) into cpHotkeyInfo["mapping_info"]

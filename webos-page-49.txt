_nurikk_ 12/30/2022 1:26 PM
Hey guys, I've found a way how to remove annoying advertisements shelfs
from webos homescreen Currently it's quite crude solution but I want to
share with you. The Idea is that we're going to override
/mnt/lg/cmn_data/sdp/sdx/detailconfig.json which is database for sdx
service used to render home app layout how do we do that? 1) copy file
/mnt/lg/cmn_data/sdp/sdx/detailconfig.json somewhere else like
/home/root
cp /mnt/lg/cmn_data/sdp/sdx/detailconfig.json /home/root/detailconfig.json
2) Edit /home/root/detailconfig.json find ai_home_info and remove all
garbage from ai_home_info key, I personally keep HOME_SH_APPS,
HOME_SH_HOMEDASHBOARD, HOME_SH_BROWSER make sure that you didn't make
any syntax mistakes, feel free to use online tools like
https://jsoneditoronline.org/ 3) Bind mount file
mount --bind /home/root/detailconfig.json /mnt/lg/cmn_data/sdp/sdx/detailconfig.json
4) restart services pkill -f sdx pkill -f com.webos.app.home As result
ad shelf are completely gone. You can add command from (3) into your
/var/lib/webosbrew/init.d executing commands 1 by 1:
    echo 'pkill -f sdx' > /var/lib/webosbrew/init.d/ad_killer
    echo 'mount --bind /home/root/detailconfig.json /mnt/lg/cmn_data/sdp/sdx/detailconfig.json' >> /var/lib/webosbrew/init.d/ad_killer
    echo 'pkill -f sdx' >> /var/lib/webosbrew/init.d/ad_killer
    echo 'pkill -f com.webos.app.home' >> /var/lib/webosbrew/init.d/ad_killer
    chmod +x /var/lib/webosbrew/init.d/ad_killer
OR run automated script:
https://github.com/nurikk/lg-webos-ad-killer#installation Tested on my
C2 with webos7. Make sure that you've cleaned up in step (2) (edited)

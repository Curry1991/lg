Found this at http://webos-forums.ru/topic6886.html
    Steps to add an app as an input device. I am using webvideo caster as an example. 
    1. Edit appinfo.json.
    vi /media/cryptofs/apps/usr/palm/applications/com.instantbits.cast.webvideo/appinfo.json
    2. Add "supportGIP":true and ensure largeIcon is set. 
    3. Reboot to apply the appinfo.json changes.
    reboot
    4. Add the app as an input device. 
    luna-send-pub -n 1 'luna://com.webos.service.eim/addDevice' '{"appId":"com.instantbits.cast.webvideo", "pigImage":"","mvpdIcon":""}'
    To remove the app as an input device. 
    luna-send-pub -n 1 'luna://com.webos.service.eim/deleteDevice' '{"appId":"com.instantbits.cast.webvideo", "pigImage":"","mvpdIcon":""}'
I edited it to be more clear and up to date. (edited)

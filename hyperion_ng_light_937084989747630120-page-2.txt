From Lord-Grey of hyperion.ng team: > I added for you three build
flags > (see my Hyperion Light 2 development branch -
https://github.com/Lord-Grey/hyperion.ng/tree/light2) > > 1.
ENABLE_EFFECTENGINE > If OFF, Hyperion will be build without python 3
and effect-engine, > as well as the UI does not offer any effects,
besides color or image ones. > > 2. ENABLE_JSONCHECKS > If OFF, there
will be no checks on the JSON and schema definitions. Combined with 1.
no python should be required overall. > If ON, minimum python 2 is
needed. It is recommended that checks are done during the build. > > 3.
ENABLE_DEV_SERIAL > If OFF, hyperion will be build without Serial
devices to avoid the Qt:SerialProt dependency > > plus as a bonus, you
can disable network LED devices via: > ENABLE_DEV_NETWORK > > @ALL Happy
to get your feedback, if I missed to cover something or if things are
not working any longer.... > Sorry, on 2. ENABLE_JSONCHECKS, you need to
disable it. > I had to fix the schema checking and this works with
python3. > So you should disable ENABLE_JSONCHECKS and
ENABLE_EFFECTENGINE to not have a python dependency (edited)

I summon you, masters of cmake and webosbrew. The guys over @
hyperion.ng were so nice to extend their build-flags even more to gain a
truly light-version of hyperion.ng - which almost configures  If
somebody could chime in and give it a try/tweak, that would be greatly
appreciated. Rundown of commands
    # Download patch
    wget https://gist.githubusercontent.com/tuxuser/7a31b0ae7394578fcea8ceddf21833d2/raw/2048f450d0110e174c6ae6403d15a0521e456424/hyperion.ng-light2-patch.diff
    # Clone repo
    git clone --recursive https://github.com/Lord-Grey/hyperion.ng
    pushd hyperion.ng
    git checkout light2
    patch -p1 < ../hyperion.ng-light2-patch.diff
    mkdir build; pushd build
    # Source build environment
    . /opt/webos-sdk-x86_64/1.0.g/environment-setup-armv7a-neon-webos-linux-gnueabi
    cmake \
      -DCMAKE_TOOLCHAIN_FILE=/opt/webos-sdk-x86_64/1.0.g/sysroots/x86_64-webossdk-linux/usr/share/cmake/OEToolchainConfig.cmake \
      -DHYPERION_LIGHT=ON \
      -DENABLE_EFFECTENGINE=OFF \
      -DENABLE_JSONCHECKS=OFF \
      -DENABLE_DEV_SERIAL=OFF \
      -DENABLE_DEV_USB_HID=OFF \
      -DENABLE_DEV_WS281XPWM=OFF \
      -DENABLE_DEV_TINKERFORGE=OFF \
      ..

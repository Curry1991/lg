I was writing a guide, in case it helps anyone Idiots (unfinished) guide
to building a module 1. Setup ubuntu 22 or higher (use VM) 2. Grab all
tarballs from lgopensource site for your model 3. Extract all tarballs
4. Locate the toolchain (sdk) installer, an sh file which should be in
the Chromium folder 4a. should be similar to
"starfish-sdk-x86_64-*-toolchain-.sh" 4b. will be misc characters
related to your version/firmware 5. Run the installer from terminal, and
accept defaults. 5a. Ignore Icecc error if you get one 6. Locate the
Kernel source, a tarball which should be in the code folder 6a. should
have any combination of the following in name: linux, kdriver, <chipset>
(e.g. SIC) 6b. should contain a README with references to building the
kernel (e.g. "to compile linux kernel and bsp kernel driver...") 7.
Install packages ("sudo apt install NAME") GCC, make, flex, bison,
libncurses-dev, libssl-dev, libelf-dev 8. Locate the Kernel source tree
folder 8a. should be one directory deeper 8b. should contain a makefile
8c. should contain a README that directly references building the linux
kernel 9. Grab your TV's config.gz, rename to .config, throw in root of
kernel source tree 9a. If you don't have one ?????? 10. Run from
terminal "make oldconfig" 10a. Hit enter a million times 11. Run from
terminal "make menuconfig" 11a. A menu (of sorts) will appear 12. Enable
modules ("y" key on each of the following). Navigate through the
following lists to find Device Drivers > USB Support > USB Serial
Converter 12a. USB_Support 12b. USB Serial Converter Support 12c.
YOUR-DRIVER-NAME (e.g. Winchiphead CH341...) 13. Save (as .config) 14.
Exit menuconfig 15. Run from terminal "make prepare" 16. Make the
driver; run from terminal "make PATH" OR "make modules" 16a. PATH = path
to the driver file (e.g. "make /drivers/usb/serial/ch341.ko")

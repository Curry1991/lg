protocol” box must also be checked and the appropriate “White LED

In this case, you can try using the LG Input Hook app from the Homebrew
Channel to place the daemon on a button on your remote control. If you
press the button, PicCap will start, if you press it again, PicCap will
stop. I have set it to the red button so that it can switch off during
the day. To test, you can run the whole code in SSH/Telnet and see if
the LEDs still light up. PicCap ON-OFF:
if luna-send -n 1 'luna://org.webosbrew.piccap.service/status' '{}' | grep '"isRunning":true'; then luna-send -n 1 'luna://org.webosbrew.piccap.service/stop' '{}' ; else luna-send -n 1 'luna://org.webosbrew.piccap.service/start' '{}' ; fi
Key codes on the LG Full Function Standard TV remote control, see LG.
Keys.txt. (edited)

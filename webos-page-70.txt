Expanding more about sedata's key, it's the chipset OTP key and is never
handed out directly. The hardware uses it internally to decrypt data but
it never leaves the IC, not even in CPU registers. The only way to dump
that is power correlation attacks afaik (edited)

Harder but doesn't require process injection like gdb or instrumentation
06/10/2019 8:52 AM

library in RELEASE (edited)
06/10/2019 8:52 AM
The manual way involves using gdb
06/10/2019 8:50 AM

over time (edited)

the decrypted data

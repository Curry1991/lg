I have collected a few facts here, so that everyone concerned can
quickly find the solution in connection with the latest firmware, update
and crashd method. “crashd” method after update with firmware version
03.30.16. “Applied a known kernel security vulnerability patch (
CVE-2021-4154, CVE-2022-2588)” After an LG firmware update 03.30.16,
webOS: 7.3.0 under /var/log/jail_app.conf a line in .conf files “mount
rw /var/log/crashd” is left out, so that no rooting is possible see
picture. This can have the consequence that in /var/log first no crashd
directory is inserted, and the LG can not get “root” rights with
“crashd” method. This is normally created by Developer Mode App. The
consequence is that when executing in webOS Device Manager terminal the
(touch /var/log/crashd/“x;telnetd -l sh”) command the following error
may appear in the output window of terminal. 1. “No such file or
directory” 2. “Permision denied” Workaround: Replace the existing
jail_app.conf and jail_app.conf.sig with the new files (jail_app.conf
and jail_app.conf.sig) using the Device Manager for webOS under Files in
/media/developer/. And restart the TV in Terminal with “reboot”. After
the restart, just repeat the crashd method. jail_app.conf and
jail_app.conf.sig Download:
https://discord.com/channels/407937994037919756/822443030761046017/1068345500027326464
Thanks to @kitsuned for the files and to everyone else involved for
finding the bug. (edited)

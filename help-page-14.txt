satdx62 12/09/2025 2:42 PM
Yes, this is annoying, of course, because root privileges are required
for certain things. But even with root privileges, in order to avoid
overloading the flash memory, you have to mount the .kodi folder on a
USB stick under /tmp/usb/sda/sda1/. You can check whether your USB stick
is recognized in this directory. If so, try mounting it. Then copy the
entire .kodi folder from
/media/developer/apps/usr/palm/applications/org.xbmc.kodi/ to the
directory on the USB directory /tmp/usb/sda/sda1/ and delete the entire
contents of the .kodi folder on the TV. The folder must remain empty.
The .kodi folder must be mounted with the following single commands (one
after the other) in terminal/PuTTY SSH:
    #!/bin/sh
    jailer -S -t native_devmode -p /media/developer/apps/usr/palm/applications/org.xbmc.kodi -i org.xbmc.kodi
    mount -o bind /tmp/usb/sda/sda1/.kodi /var/palm/jail/org.xbmc.kodi/media/developer/apps/usr/palm/applications/org.xbmc.kodi/.kodi
To make this permanent, you would need to create a script and copy it to
/var/lib/webosbrew/init.d/ so that the mount is permanent. I don't know
if the script can be created without root access to
/var/lib/webosbrew/init.d/, but you can try if the Developer Mod app is
active. (edited)

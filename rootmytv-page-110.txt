infowski 06/17/2021 8:51 PM
This does not "stay" applied across reboots, so if you want to do
something on every startup you need to create a file in
/var/lib/webosbrew/init.d and make it readable. Like this:
    # Ensure directory exists
    mkdir -p /var/lib/webosbrew/init.d
    # Create some example script (you can also just copy some file using scp/rsync over there...)
    cat <<EOF >/var/lib/webosbrew/init.d/block-domains
    #!/bin/sh
    echo "127.0.0.1 some.random.domain" >> /etc/hosts
    EOF
    # Make it executable
    chmod +x /var/lib/webosbrew/init.d/block-domains

Im not sure about ws2812b, but i think they need an level shifter. So
you may need one. Tho you can try at least an cheap 100ohm resistor,
since that's a hack to make sk6812 working. For software it's pretty
easy, you install Arduino IDE 2.0... Then you go into arduino ide
settings and add the board url for esp32 (that's documented in GitHub)
but ask if you need help... Then you install inside arduino ide in the
board library window the esp32 board support but Version 1.07 or the
newest 1.xx version (i don't remember which exactly it is, but you have
a dropdown). Don't install by default the newest v2.xx version... Then
you have to install one more library, but that's written in
Hyperserialesp32 github either, adalight or sth like that (however read
the github) Then you download the .ino from the GitHub and put it inside
an new folder. The folder name and the filename (of .ino) should be
identical. Then you have simply to adjust in the ino file the top 3/4
lines, but they're commented with good descriptions. Then connect the
esp32 with pressing the boot button with your pc over usb (ch9102)...
Select your board inside arduino ide and the correct com port... Hit
flash and you're done

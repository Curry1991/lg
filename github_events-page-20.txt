[webosbrew/hyperion-webos] New comment on issue #62: Question about
added video output latency
We are not aware of that. Generally (highly oversimplified) video coming
from inputs onto the display basically bypass the CPU/GPU. Video capture
only "reads out" buffer that are already displayed on the display. UI
capture extracts rendered frames from the GPU (GPU is only responsible
for rendering of non-video parts on the screen). The only effect
hyperion-webos has on a TV is increased network usage and CPU usage -
which can cause UI to "slow down" a little, but *not* affect video
play...

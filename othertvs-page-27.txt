.suikale 09/29/2021 8:10 AM
seems that the rtice software uses .tbl files which are converted to
appropriate .config files and are then uploaded to the device. The
.config files are used to set config bytes, so the memory map you
provided may not be enough. This is an example snippet from a
boot_ddr2.config.tbl
    rtd_outl(0xb8060050,0x00000001); //ST_BUS = 27 MHz 
    ScalerTimer_DelayXms(1);
    rtd_outl(0xb8000200,0x00000001); //SCPU_clk=27 MHz 
    ScalerTimer_DelayXms(1);
    rtd_outl(0xb8000204,0x00000001); //Main UART Clock Source Select = 27 MHz 
    ScalerTimer_DelayXms(1);
    /* 5.4.1  SCPU PLL control register */
    rtd_outl(0xb8000400,0x001b9400); //300~500  SCPU clock IC Max 400Mhz
    rtd_outl(0xb8000404,0x00000005); //398.25M
    rtd_outl(0xb8000404,0x00000007);
    ScalerTimer_DelayXms(1);
    rtd_outl(0xb8000404,0x00000003);
    /* 5.4.6  BUS PLL Control Register */
    rtd_outl(0xb8000480,0x00350b52); //200~450  BUS clock IC Max 405Mhz
    rtd_outl(0xb8000488,0x00000005); //405M
    rtd_outl(0xb8000488,0x00000007);
    ScalerTimer_DelayXms(1);
    rtd_outl(0xb8000488,0x00000003);

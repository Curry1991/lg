What is a UTV file? A UTV file is a firmware update file used by a Vizio
SmartCast TV. It contains data the TV uses to update to the latest
version of the SmartCast TV software. You can use a UTV file to manually
update a TV's firmware without connecting to the Internet. More
Information Typically, Vizio SmartCast TVs automatically update to the
latest version of the SmartCast TV software. However, if your TV is not
connected to the Internet, you must update it manually. To retrieve the
latest version of your TV's firmware, stored in a UTV file, go to the
Firmware Information section of Vizio's support website. There, you can
download the most recent version of SmartCast TV firmware. This file
will arrive as a .ZIP file, which contains the UTV file. UTV files are
typically named for the version of SmartCast TV firmware they contain.
For example, a UTV file may be named 2.72.34-4.utv. This file contains
firmware version 2.72.34-4. How to open a UTV file UTV files are not
meant to be opened. To install the firmware update a UTV file contains
on your Vizio SmartCast TV: Place the UTV file on a USB flash drive.
Turn on your TV. Insert the flash drive containing your UTV file into
your TV's USB port. Your TV will show a message and begin installing the
firmware update. During this process, your TV will reboot at least two
times. Place on a USB flash drive and install on your Vizio SmartCast TV

[awawa_dev]
[] sh4d0w. I'm very occasionally getting all my LED's flashing to solid
white, just for a single refresh or so ...
awawa_dev 02/07/2023 2:10 PM
UDP usually has a checksum protection, if it runs over TCP there is an
additional one, so you may experience delays and lost packets but not
corrupted packets. Maybe you are using wrong type of level shifter
(I2C?), too long data cable, unstable power supply or it's just WLED
when e.g. some wifi related interrupts break something which should not
touch at the moment like LED rendering. Especially true for ESP32
boards. This is the price of creating a combine-harvester for everything
based on many libraries from which each can bring its own bugs (many of
which are only revealed in mutual interactions). Anyway, I recommend a
cable connection that has been specially designed and optimized for
ambient lighting. (edited)

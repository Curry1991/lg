Things to test out: Run install command above Launch Homebrew Channel
and wait a couple of seconds - you should get a notification in upper
right corner like /var/lib/webosbrew/startup.sh updated! or
/media/cryptofs/apps/usr/palm/services/com.palmdts.devmode.service/start-devmode.sh updated!
(assuming you've never modified these files yourself!) Go to Settings,
make sure it still says "Root status: OK" Press Reboot After a reboot
make sure ssh/telnet is still working Then you can launch Homebrew
Channel, and enable "Failsafe mode" in Settings (to forcefully enable
it), then press Reboot * After a reboot you should get a nice alert that
says failsafe mode has been triggered, with an option to reboot a TV -
check if telnet works properly now - then after pressing "Reboot now" in
that prompt it should no longer have failsafe mode enabled. In Homebrew
Channel Settings you should be able to enable "Non-free software" -
after going back to main Homebrew Channel view (which should
automatically refresh now) you should see that Dinosaurs game... 
After installing any app, you should get a notification with
human-readable application name (it was application id before). * All
notifications should have Homebrew Channel icon now (it was a gray
placeholder icon before) (edited)

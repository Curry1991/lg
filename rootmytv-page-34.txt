[] trueblue1878 Hi all, I rooted and installed kodi 21, but my TV
doesn't have enough internal memory to install the...
satdx62 09/08/2024 10:42 AM
You must transfer the contents of the .kodi folder and its subfolders to
a USB 3.0 stick. Simply create a .kodi folder in the root directory of
the USB stick. Check under /tmp/usb/sda/sda1/ whether the .kodi appears:
/tmp/usb/sda/sda1/.kodi Next, you need to mount the .kodi folder in the
System. Use Putty SSH or Terminal for this:
jailer -S -t native_devmode -p /media/developer/apps/usr/palm/applications/org.xbmc.kodi -i org.xbmc.kodi
mount -o bind /tmp/usb/sda/sda1/.kodi /var/palm/jail/org.xbmc.kodi/media/developer/apps/usr/palm/applications/org.xbmc.kodi/.kodi 
Now you can copy the whole content from
/media/developer/apps/usr/palm/applications/org.xbmc.kodi/.kodi/ to /tmp/usb/sda/sda1/.kodi/.
To make the complete thing work after a new cold start, you have to
create a script and copy it to /var/lib/webosbrew/init.d/. You can use
my kodi file for this. Make sure that the file authorization is set to
774. The contents of the .kodi folder from
/media/developer/apps/usr/palm/applications/org.xbmc.kodi/.kodi/ can be
deleted completely to free up memory. Kodi will now install all add-ons
in /tmp/usb/sda/sda1/.kodi/ if everything has been done correctly.

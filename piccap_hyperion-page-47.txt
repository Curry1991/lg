To generate a config, copy your hyperion.ng database
(~/.hyperion/db/hyperion.db) and call the hyperion.rs binary like this:
    # First, check if everything works by printing to console
    ./hyperiond-rs -d path/to/hyperion.db --dump-config
    # If all looks good, redirect to file
    ./hyperiond-rs -d path/to/hyperion.db --dump-config > config.toml
Now you can use the config.toml like so ./hyperiond-rs --config.toml -vv

@infowski @ww I found I quick and easy way to have your own working
Linux chroot within the TV. I used Alpine Linux with armv7 architecture.
These are the official instructions (it takes 5 minutes):
https://wiki.alpinelinux.org/wiki/Alpine_Linux_in_a_chroot Summary of
commands (you only need to customize the first 2):
chroot_dir=/media/alpine mirror="http://<mirror>/alpine/edge/main" # See https://mirrors.alpinelinux.org mkdir -p $chroot_dir && cd $chroot_dir curl -LO ${mirror}/armv7apk-tools-static-2.12.9-r1.apk tar -xzf apk-tools-static-*.apk && rm apk-tools-static-*.apk ./sbin/apk.static -X ${mirror} -U --allow-untrusted -p ${chroot_dir} --initdb add alpine-base mount -o bind /dev ${chroot_dir}/dev mount -t devpts devpts ${chroot_dir}/dev/pts mount -t proc none ${chroot_dir}/proc mount -o bind /sys ${chroot_dir}/sys echo -e 'nameserver 1.1.1.1\nnameserver 8.8.8.8\n' > ${chroot_dir}/etc/resolv.conf mkdir -p ${chroot_dir}/etc/apk echo "${mirror}" > ${chroot_dir}/etc/apk/repositories chroot ${chroot_dir} /bin/ash -l apk update
Alpine Linux in a chroot

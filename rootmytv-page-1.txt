I have been digging into this a bit, may be useful to others On the live
system, the build timestamp can be accessed very easily using any of
these commands:
    nyx-cmd OSInfo query webos_build_datetime
    nyx-cmd OSInfo query --format=json
    cat /var/run/nyx/os_info.json
But in epk itself, you have to find a partition that has
/usr/lib/nyx/modules/nyxOSInfo.module or
/usr/lib/nyx/modules/nyxOSInfoMain.module. And even that file isn't in
plain text (less that on live TV to see). That module file is loaded by
/usr/lib/nyx/nyxcmd/libnyxcmdModuleOSInfo.so binary on my TV when I run
nyx-cmd OSInfo query --format=json that module file is in otycabi |
otycabi-arib | otycabi-atsc | otycabi-dvb | otycabi-global (sometimes
you have to extract super.pak to get to them) This covers most of the
new EPKs, but there are still some edge cases (edited)

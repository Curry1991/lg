In case of using Windows, indeed, you already have a fully featured VLC,
well, except Dolby Vision of course, since VLC doesn't support it, only
HDR10, so colors will look wrong. However, it is possible to play Dolby
Vision video's correctly through Windows 11's own video players (in this
case LLDV or client side Dolby Vision will be used, not TV side Dolby
Vision), as long as the TV supports DV and has the DV block in the EDID.
You can edit the EDID that Windows uses for your display, by exporting
the EDID of your display using something like CRU, then hex editing (or
using AW EDID Editor, go to 'Vendor-Specific Video' tab) to change a bit
that tells Windows to use Dolby Vision (basically increase the sixth
position in the string by one, so if it's 6>7, 3>4 or e>f, etc, it's a
hexidecimal number), then importing that EDID with CRU. And install
'Dolby Visions Extensions' Windows Store app. Windows 11's video player
will then correctly play Dolby Vision, client side (eg, LLDV).
https://github.com/balu100/dolby-vision-for-windows/blob/main/README.md
Otherwise, you can use MPV to correctly play (LLDV) Dolby Vision if you
set it up right. The other upside of VLC on Windows, if you have modern
Nvidia GPU, VLC will support RTX Super Resolution and RTX HDR. You can
also use a tool like SpecialK, if you watch a HDR10 movie, if you inject
a tool SpecialK into VLC, then enable the HDR Widget, enable HDR10
profile, enable Perceptual Boost and maybe Color Boost at a lower value,
you can get, imo, Way nicer highlights. Otherwise, to add more HDMI
ports, you can look at HDMI switchers. Also, if ever plan to build for
yourself an actual good sound setup with several big, accurate and great
speakers in a 5.1/7.1 or 7.1.4 configuration so you have your own home
cinema, using an Denon AVR, ideally the x3000h series or higher, cause
it supports Audyssey XT32, both digital and analog video input and
external amplifier, the AVR offer 8x HDMI 2.0b or 2.1 ports to attach
devices too. (edited)

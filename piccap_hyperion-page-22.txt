Orange is usually default color set in WLED and in this case the lamps
were already ON before HyperHDR took the control. So when HyperHDR exits
with 'Restore lights original state when disabled`, first send the black
color (default behavior on the light source is going to be disabled),
then it restored original WLED: in this case enabled with default orange
color. Or the WLED configuration needs to be fixed or disable 'restore'
option in HyperHDR to avoid it.

follow this, Hyperion installed on your TV does not know your WLED

Internet browser such as Microsoft Edge, Chrome, or Firefox. Just enter
the IP address of your TV followed by :8090 instead of www.google .com.

the LED strip. Next you put such ESP into USB port and configure the
Adalight driver in HyperHDR to use it. ESP serial chip must be supported
by OS: it's not a problem for Windows or regular Linux, LG webos
natively supports ESP32 with CH9102x serial chip (like ESP32 MH-ET LIVE
mini) and ESP32-S2 lolin mini boards. Wifi is easy, the cable connection
is optimal  If you are not sure it's best to have ESP board that
supports both solutions: ESP32 MH-ET Live mini. (edited)

    Some OS and/or drivers may activate RTS and or DTR automatically when opening the serial port (true only for some serial terminal programs, not esptool.py), pulling them low together and holding the ESP in reset. If RTS is wired directly to EN then RTS/CTS “hardware flow control” needs to be disabled in the serial program to avoid this. An additional circuitry is implemented in order to avoid this problem - if both RTS and DTR are asserted together, this doesn’t reset the chip. The schematic shows this specific circuit with two transistors and its truth table.
    If this circuitry is implemented (all Espressif boards have it), adding a capacitor between the EN pin and GND (in the 1uF-10uF range) is necessary for the reset circuitry to work reliably. This is shown in the ESP32 Module section of the schematic.

better because it allows you to control/test the LED strip directly and
it will show if the serial chip is working correctly. Later install
HyperSerialESP32 to have lower power usage and optimized control over
the LED strip rendering. BTW if you have ESP32-S2 mini, WLED doesn't
support S2 so HyperSerialESP32 is the only option then.

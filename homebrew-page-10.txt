ah i see. It seems you tried to merge the documented approach of
overwriting existing and adding new files in one. If your goal is to
have both (seeing your modified and new files in com.webos.app.home) its
sufficient to use the mount overlay command, but reversing the order in
-olowerdir. Basically a
mount -t overlay overlay -olowerdir="$OVERRIDE_BASEPATH":"$QML_DIRECTORY" "$QML_DIRECTORY"
olowerdir builds the view from right to left, so the left-most directory
will be the most top one --> the one you see in the end But: Using a
directory for lower-dir and mountpoint at the same time is unstable
since it creates a circular dependency. Better to first create a
copy/mount of the dir in a temp dir, create a overlay from both as
merged dir and mount that then onto the target:
mount --bind <path-to-com.webos.app.home> /tmp/weboshome-stock mount -t overlay overlay -olowerdir="<path-to-your-files>:/tmp/weboshome-stock" /tmp/weboshome-merged mount --bind /tmp/weboshome-merged <path-to-com.webos.app.home>
Didn't test it, but should work in theory.

    set -e -o pipefail
    QML_DIRECTORY=/usr/palm/applications/com.webos.app.home/qml
    OVERRIDE_BASEPATH="$(cd "$(dirname "$(readlink -f "$0")")" && pwd)"
    # Bind-mount existing files that are being overridden
    find "$OVERRIDE_BASEPATH" -type f ! -name "apply.sh" | while read -r file; do
        override="${file#$OVERRIDE_BASEPATH/}"
        target_path="$QML_DIRECTORY/$override"
        # Only bind-mount if target file exists (override case)
        if [ -f "$target_path" ]; then
            if mountpoint -q "$target_path" 2>/dev/null; then
                echo "! Already bind-mounted: $target_path"
                continue
            fi
            echo "✓ $override → $target_path"
            mount --bind "$file" "$target_path"
        fi
    done
    # Mount overlay for new files
    if ! mountpoint -q "$QML_DIRECTORY" 2>/dev/null; then
        echo "Mounting overlay: $QML_DIRECTORY"
        mount -t overlay overlay -olowerdir="$QML_DIRECTORY":"$OVERRIDE_BASEPATH" "$QML_DIRECTORY"
    fi

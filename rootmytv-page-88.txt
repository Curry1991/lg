PicCap autostart workaround: 1. Connect to your rooted TV with Homebrew
Channel 0.5.1 via SSH. SSH must be enabled in Homebrew Channel settings.
Default Credentials: Username: root Password: alpine 2. Run this command
to overwrite the contents of the autostart entry in the init.d
directory:
echo "/media/developer/apps/usr/palm/services/org.webosbrew.piccap.service/hyperion-webos -a 127.0.0.1 -p 19400 -f 25 -x 288 -y 180 &" > /var/lib/webosbrew/init.d/piccapautostart
3. Run this command to allow execution of the autorun script:
chmod +x /var/lib/webosbrew/init.d/piccapautostart (edited)

crashd and piccap directions: 1. Enable Developer Mode on your TV 2. get
DevMode Manager from here :
https://github.com/webosbrew/dev-manager-desktop/releases/tag/v1.8.2 3.
set up your TV and install homebrew channel 0.5.1 from

DevMode Manager go to terminal and execute

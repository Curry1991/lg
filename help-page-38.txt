mr.meorzipan 04/06/2024 2:19 AM
If you want an easy gui method to install the YouTube Adfree app, use
WebOs Devmode Manager:
https://github.com/webosbrew/dev-manager-desktop/releases If you have
already rooted your TV, do Not install the ~~Dev Mode~~ app on your LG
TV (or you will lose root), instead, enable the SSH server within the
options of Homebrew Channel on your TV. Other than that, within WebOs
Device Manager, use the SSH Server option with root, change
Authentication option from 'Private Key' to 'Password' and use 'alpine'
as password, other than that you must input the IP address of your TV.
Once connection succeeded, you can easily install whatever app Homebrew
Channel offers with a mere click of a button within the GUI of WebOS Dev
Manager, from the Apps tab, you'll see a list of currently Installed
apps and an list with Available apps, you will go to the 'Available'
list, scroll all the way down to 'YouTube Adfree', click on 'Details',
then click on 'Install'. However, the version it (or WebOSBrew) offers
right now is 0.3.2, so instead you might want to download the IPK file
of 0.3.3, then go to the 'Files' tab of WebOS Dev Manager, click the +
button in the right top and upload the IPK file. Then go to the
'Terminal' tab, and run the command:
    luna-send-pub -i 'luna://com.webos.appInstallService/dev/install' '{"id":"com.ares.defaultName","ipkUrl":"/home/root/youtube.leanback.v4_0.3.3_all.ipk","subscribe":true}'

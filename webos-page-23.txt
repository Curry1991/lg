Where did you read that you need to install Developer Mode app? It's
actively being discouraged if you want to root your TV or while using a
rooted TV, cause the method we used to root the TV, was patched in some
version of the Developer Mode app, so we can't patch crashd to open
telnet and root TV. And after the Session Time runs out (cause you may
not pay attention and forget all about it), Developer Mode app would
automatically turn off 'Dev Mode' and then all third party apps will get
removed, so if you've rooted your TV and left that app installed, and
forgot about it, you'd lose root as soon the Session Time ran out, cause
it'd remove Homebrew Channel (which was granted root privileges). If you
had not rooted your TV and your TV was patched so even Dejavuln-Autoroot
(the current most easiest rooting method) doesn't work, then maybe it
might make sense to be interested in using Developer Mode, since you
wouldn't have root, AmbiLight setup using PicCap would not be available,
as well blocking update notifications, remapping your remote and several
other cool features (all requires root privileges), but you can at least
install YouTube Adfree and some other homebrew apps. Since you mention
you have root, Developer Mode is not relevant to you for connecting to
your TV. Instead it is then being recommended, to enable the SSH server
in Homebrew Channel, open WebOs Dev Manager on your PC, and follow what
@satdx62 said. If the problem are those certificate errors, @hellobox is
working on a fix, he mentioned this in # unknown-channel , even sharing
a test build of Homebrew Channel that has the fix, but it is a test
build, so not yet an official release version, so it may have problens,
so you must install the 'Safe Updater' app beforehand (and must run it
at least once so it can gain root priveleges), the test IPK he shares
and 'Safe Updater' app you can both install through WebOS Dev Manager.

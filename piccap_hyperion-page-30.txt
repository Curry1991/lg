It appears that SDR/HDR/DV content need different LUT tables to fix them
better. So it's possible now (v19beta) to switch the LUT tables
depending on the active content. I doubt there is one magic LUT (or even
3 LUT tables for SDR/HDR/DV) that will fix the stream perfectly for all
LG TVs because something happen to the video stream when it is being
captured and it's not perfect. Still HyperHDR calibration wizard can be
used for creating&calibrating these SDR/HDR/DV LUT tables. It was
designed for calibrating HDR but one of it's strategies tests non-HDR
approach. And since we can switch LUT tables now it can be run three
times for each content to create 3 new LUT tables. Then using new JSON
it's possible to select proper LUT table in HyperHDR, depending on the
input video stream (SDR/HDR/DV). (edited)

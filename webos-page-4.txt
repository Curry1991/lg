.kriilunaus 05/04/2026 2:41 AM
That’s not entirely accurate, and it downplays the risk posed by this
kind of privilege escalation exploit. At the moment, a malicious or
compromised webOS app from the official LG App Store would be enough to
take full control of your TV. It’s also worth noting that a large share
of webOS apps embed web content that is loaded remotely (and thus could
load malicious code undetectable by LG). It also cannot be ruled out
that malware embedded in some web content displayed on the TV (e.g. as
part of an ad) could use this mechanism to gain control. dangbro
demonstrates this itself: by chaining multiple vulnerabilities as a
vehicle, the final root exploit is ultimately executed. Right now, the
only thing preventing a fully automated, unnoticed infection of a system
is the SSAP pairing prompt. And that pairing prompt has already been
bypassed in the past. So you would only really be safe if you blocked
all outgoing+incoming internet traffic, because every locally opened
website or app poses a risk. That said, there is currently no known
malware that actively exploits these vulnerabilities on webOS TVs. So if
you don’t use any unknown apps and also don’t use the browser on the TV,
you should be relatively safe for now. There is no guarantee, though.

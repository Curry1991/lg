It's not something that can really be "fixed", since webOS 4.[0-4] is
missing the feature we're currently using for autostart functionality.

newer versions of webOS. The next version of Homebrew Channel will try
to work around this to a limited extent by running `startup.sh` when the
app is launched. If anyone wants to look for new boot hooks, it would be
greatly appreciated.

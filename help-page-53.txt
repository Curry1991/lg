[For anyone trying to use USB Storage for their RA Roms on a jailbroken
LG TV] The problem: The storage of the Retroarch app is jailed but the
USB mount for the TV is outside of that jail so you may need to use this
script: https://gist.github.com/maatthc/792471812150010c935aedd34c93aedf
As the script documentation explains: The script is going to link the
actual mount point /tmp/usb/sda/sda1/ with the jailed point
/var/palm/jail/com.retroarch/media/internal To do this: 1) Download the
script and plug the USB drive into the TV 2) Turn on SSH for the TV in
the Homebrew App 3)Connect to the TV with WinSCP (user: root | pass:
alpine) 4) Use WinSCP to copy the script to the TV (I'd suggest in
directory /home/root) 5) Connect to the TV using Putty 6) Run the
command using
    sh add_usb_drive_to_retroarch_media_folder_install.sh
7) Wait for the command to complete then tap any key to reboot the TV 8)
Open RetroArch and check if the USB mounted at /media/internal (edited)

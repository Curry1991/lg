I wanted to disable the TV's built in screensaver while the Plex app was
running because the Plex app has a beautiful screensaver that randomly
displays poster art from all the movies and tv shows in your media
library. I Put this script in "/var/lib/webosbrew/init.d/" directory I
just called the file I put the script in "1". A big thank you to
Hellobox for providing this script. I believe either a letter or a
number file name is suitable and determines what order they run in. make
sure it is executable chmod +x luna-send -i
palm://com.webos.service.tvpower/power/registerScreenSaverRequest
'{"subscribe":true,"clientName":"tester"}' | while IFS= read -r line; do
timestamp="$(echo "$line" | grep -o -E '[0-9]*')"; if [[ ! -z
"$timestamp" ]]; then if luna-send -n 1
'luna://com.webos.applicationManager/getForegroundAppInfo' '{}' | grep
'cdp-30'; then echo Resetting screensaver timer... luna-send -n 1
"luna://com.webos.service.tvpower/power/turnOnScreen" '{}' fi fi ; done
& Substitute “cdp-30” for the id of your active program id that is
running when you want the screensaver disabled. command to get currently
running apps ID: luna-send -i
'luna://com.webos.applicationManager/getForegroundAppInfo'
'{"subscribe":true}'

8,400 bits (24 bits 350). To achieve 99 FPS: Required data rate = 8,400
bits 99 FPS = 831,600 bits per second Required data rate = 831,600 bits
per second / 1,000,000 ≈ 0.8316 Mbps Level Shifter max Mbps examples: ->
TXS0102 or TXB0102: 20Mbps -> 74AHCT125 (is not a level shifter, its a
quad bus buffer) -- Typical delay around 8 ns for V_CC = 4.5V to 5.5V at
25°C (according to datasheet) -- Maximum delay can be around 12 ns to 18
ns (according to datasheet) -- Worst-case rise time (t_r): 6 ns (for
V_CC = 4.5V to 5.5V) -- Worst-case fall time (t_f): 6 ns (for V_CC =
4.5V to 5.5V) -- Total worst-case time for a signal transition (rise and
fall) = t_r + t_f = 6 ns + 6 ns = 12 ns = Data rate = 1 / 12 ns ≈ 83.33
Mbps

SK6812 Basics: - The SK6812 has the following timing requirements for
its data signal: T0H (0-bit high time): 300 ns T0L (0-bit low time): 900
ns T1H (1-bit high time): 900 ns T1L (1-bit low time): 300 ns For each
bit, the total time can be either 1.2 µs (T0H + T0L) or 1.2 µs (T1H +
T1L), since the sum of high and low times for both 0-bit and 1-bit are
the same. The data rate can be calculated as the inverse of the total
time per bit: Data rate = 1 / (Total time per bit) Data rate = 1 / 1.2
µs ≈ 0.833 Mbps (833 Kbps) ---- For 350 LEDs, the total bits are 8,400
bits (24 bits * 350). Using the data rate of 833 Kbps: Minimum time =
8,400 bits / 833,000 bits per second ≈ 0.0101 seconds (10.1 ms) = The
fastest possible time 350 sk6812 leds can update all at once is 10.1ms =
FPS = 1 / 0.0101 seconds ≈ 99.01 FPS (Max archivable FPS) = The Latency

PicCap- HyperHDR on FTDI with SK6812RGBW NW For the FTDI you need a
special HyperHDR build from @_nurikk_ (@nurikk) from GitHub where,
APA102, WS2812 and SK6812RGBW are implemented.
https://github.com/awawa-dev/HyperHDR/pull/521 Here are my settings of
HyperHDR on FTDI with SK6812 RGBW NW under white LED algorithm and a
brightness of 120. If you think this is too bright, feel free to set it
to 100. With these settings, I achieved optimal basic colors and
gradients. Even the blue part is now better than with WLED itself. For
my visual impression and vision, almost PERFECT! My wall color butt TV
is white. Note: Under LED Hardware, LED Layout you have to enter the
actual LEDs number per side and the input position (first LED).
Attention. Please solder to FTDI with 3 wire coupler adapter supplied
with the LEDs. This is also the maximum length, where the data line may
have, in order to be able to pass on the data error-free. Do not connect
the red wire +5 volts. The LEDs must not draw voltage from FTDI. If the
number of LEDs exceeds 30, the FTDI board could be damaged. Since the
USB output of the TVs only provides a maximum of 1000mA. The 470 Ohm
resistor and the 1000µF electrolytic capacitor are optional, and to be
used if you have untypical flickering/flashing LEDs. But it does not
hurt if you have them and install them from the beginning.

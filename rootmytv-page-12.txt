  (Edited and shortened for clarity) Hello All, I have the solution
for using Dangbro on Windows on Chrome. No need to mess around with
Certificates, Browser settings, or need Firefox on Android etc. Just
open Powershell in Windows Terminal and paste the following :
    Start-Process "$env:ProgramFiles\Google\Chrome\Application\chrome.exe" -ArgumentList @(
      "--user-data-dir=$env:TEMP\chrome-dangbro-insecure",
      "--no-first-run",
      "--ignore-certificate-errors",
      "--allow-running-insecure-content",
      "--disable-web-security",
      "--new-window",
      "https://azoffshowy.github.io/dangbro"
    )
This command is completely safe, it only launches Dangbro in a
disposable temporary chrome profile with all the security features
regarding certificates etc disabled. When you close this window it will
wipe this profile and your main Chrome remains unaffected. DON'T DO
EVERYDAY WORK IN THIS CHROME PROFILE, IT IS ONLY FOR DANGBRO. This is
needed as otherwise there is no way possible to make the exploit run on
Windows. Mainly because modern certificates need a "Subject Alternative
Name" field which the LG certs have missing. This is the field that
tells the browser, "Hey, 192.168.x.y is a valid alternative name for the
device you're trying to verify". Since this field is blank, Dangbro can
never make a websocket connection to the TV, even if you open the
certificate in a separate tab. accept the risk and see the "Hello World"
message. (Firefox on Android may be able to make it work today, but it
is not the intended behavior and is a security loophole that may be
fixed in the future.) Therefore I just chose to NUKE  the whole
security system instead, temporarily ofc ;) Dangbro developer can fix
this by wrapping his app in an Electron wrapper with these security
features disabled and make it a downloadable app that will work across
all Desktop OS. (edited)

hellobox. 04/19/2024 3:03 PM
LG uses SoCs from realtek, mediatek (although all the current ones are
actually mstar designs), and LX. LX was spun off from LG, and those
designs are custom for LG TVs. the rtk/mtk ones are possibly slightly
customized for LG in the past they used actual mtk designs, but the last
one was A5LR in 2015 (webOS 2). in the consumer (HE) market, LX SoCs
have been used only in top-of-the-line (8K and high-end OLED) models
since 2020, although in 2023 they returned to using an LX SoC (M23) in
slightly worse models. LX SoCs have been used more widely (in the past,
i believe everything but the very worst models were exclusively LX) in
commercial (signage/hospitality; ID) models, although recently they seem
to have been using rtk (e.g. K8Lp/K8Hp) for some hospitality (edited)

    FROM ubuntu:22.04
    ENV TZ=Europe/Berlin
    RUN ln -snf /usr/share/zoneinfo/$TZ /etc/localtime && echo $TZ > /etc/timezone
    WORKDIR /build
    RUN apt update && apt install -y git build-essential binutils file wget cpio unzip rsync bc ccache tzdata
    RUN git clone https://github.com/openlgtv/buildroot-nc4
    WORKDIR /build/buildroot-nc4
    RUN make webos_tv_defconfig && make sdk
    WORKDIR /build
    RUN tar xzvf buildroot-nc4/output/images/arm-webos-linux-gnueabi_sdk-buildroot.tar.gz
    RUN apt update
    RUN git clone --depth 1 https://github.com/xbmc/xbmc kodi
    RUN mkdir kodi-deps
    WORKDIR /build/kodi/tools/depends
    RUN apt update && apt install -y curl libcurl4-openssl-dev gawk zlib1g-dev bison flex openjdk-17-jdk
    RUN ./bootstrap
    RUN ./configure --prefix=/build/kodi-deps --host=arm-webos-linux-gnueabi --enable-debug=no \
        --with-toolchain=/build/arm-webos-linux-gnueabi_sdk-buildroot
    RUN make -j$(getconf _NPROCESSORS_ONLN)
    RUN apt update && apt install -y pkg-config pkg-config libssl-dev libglib2.0-dev
    WORKDIR /build
    RUN git clone --depth=1 https://github.com/webosbrew/ares-cli-rs
    RUN curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- --profile minimal -y
    ENV PATH=/root/.cargo/bin:$PATH
    WORKDIR /build/ares-cli-rs
    RUN cargo install cargo-deb
    RUN cargo deb -p ares-package
    RUN dpkg -i /build/ares-cli-rs/target/debian/ares-package_0.1.3-1_arm64.deb
    RUN ln -s /build/kodi-deps/aarch64-linux-gnu-native/bin/ninja /usr/bin/ninja
    WORKDIR /build/kodi
    RUN make -C tools/depends/target/cmakebuildsys
    WORKDIR /build/kodi/build
    RUN make -j$(getconf _NPROCESSORS_ONLN)
    RUN echo "set auto-load local-gdbinit" >> /root/.gdbinit
    RUN echo "add-auto-load-safe-path /" >> /root/.gdbinit
